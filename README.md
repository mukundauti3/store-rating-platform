# Store Rating Platform

## Tech Stack

* Frontend: React.js + Vite
* Backend: Node.js + Express.js
* Database: MySQL
* Authentication: JWT

## Features

* User Registration & Login
* Store Listing and Search
* Store Rating System
* Admin Dashboard
* Store Owner Dashboard
* Role-Based Authentication

### Backend

```bash

npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
